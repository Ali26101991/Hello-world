File Handling : opening file, performing operations on file and closing the file.
Type of files : i) text file  ii) Binary file
i) text file : Data stored in the form of characters.
ii) Binary files :  Data stored in the form of Bytes (group of 8 bits )-- audio files, video files , image files.
Two ways to handle data storage : i) file handling  ii) Database
